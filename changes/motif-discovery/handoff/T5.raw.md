**Invalidating (must change before running)**

1. **Unreachable p-values / invalid pooling.** About 87k k-mers × 3 regions gives roughly 262k tests. BH's first rank needs p ≈ 0.05/262k ≈ 2e-7, but 100 shuffles give a minimum p of 1/101, so nothing can pass. The proposed "pooled null per k-mer across 100 whole-set shuffles" is still only 100 draws per k-mer. Pooling across k-mers is invalid because null coverage depends on k-mer composition (CpG, UpA, GC).
   *Fix:* Use shuffles to estimate a per-cluster expected count or presence probability for each k-mer. Then compute an analytic tail: Poisson-binomial for coverage, or a Stouffer/z-score across clusters. Verify calibration on held-out shuffles.

2. **Gate G1 (and the T3 acceptance criterion) is mis-specified.** "≤5% hits at q<0.05" would accept about 13k false discoveries. Under a global null, BH should give zero hits in ≥95% of runs. The gate is also circular if the null data are generated by the same shuffler as the test null.
   *Fix:* Run ≥20 null datasets. Require ≥1 discovery in ≤5% of them, and require a uniform p-value QQ plot. Generate null data with Markov-2 or real sequences from a different generator.

3. **Presence saturation and length confound.** Genomes span 200–35,000 nt.
   - For k ≤ 6 in long genomes, presence is ≈1 for nearly all k-mers, so there is no power.
   - Long genomes dominate coverage.
   - The log2(obs/null) ≥ 1 threshold is impossible when null coverage exceeds 0.5. It also favours rare k-mers with unstable near-zero denominators.
   
   *Fix:* Use count-based obs/expected per cluster with a pseudocount, combined across clusters. Alternatively, use fixed-length windows. Drop k = 4–5, or analyze them only within regions.

4. **Biological units undefined.** The plan does not handle:
   - Strand and sense: for negative-sense or ambisense viruses, the genomic 5' end is not an mRNA 5'UTR.
   - Segmented genomes.
   - DNA viruses within RefSeq.
   - Poly-A tails and low-complexity sequence.
   - How "presence per cluster" is computed: any-member presence inflates large clusters.
   
   *Fix:* Restrict to RNA viruses. Orient sequences to mRNA sense. Make the segment the sequence and the genome the cluster member. Use the cluster medoid only. Mask homopolymers and low-complexity regions.

**Weakening (fix or state as limitation)**

5. **Pseudo-replication.** RefSeq is already one record per species, so 90% clustering collapses almost nothing. Clusters within a genus or family are not independent, and the effective n is closer to the number of genera or families (8).
   *Fix:* Require enrichment in each counted family separately, using a per-family test. Report a leave-one-family-out analysis. Treat "≥3 clusters" as descriptive only.

6. **Coding confound.** A dinucleotide shuffle destroys the codon and amino-acid structure of ~90% coding sequence, so hits will be dominated by codon-usage and protein-motif k-mers.
   *Fix:* Use a codon-preserving or synonymous shuffle within CDSs, or restrict testing to annotated non-coding regions.

7. **Multiple-testing dependence.** Tests are nested (an 8-mer implies its sub-k-mers), overlap, and repeat across regions. BH's PRDS assumption is plausible but unproven.
   *Fix:* Pre-specify a primary k (e.g., 6–8) and a primary region. Use BY or hierarchical testing (region → k → k-mer). Collapse nested hits into maximal motifs before counting.

8. **Family-breadth criterion.** Applied post hoc, it is a filter, not a test. Families have unequal cluster counts.
   *Fix:* Pre-specify it as a conjunction test: each of ≥2 families has q < 0.05. Report the number of k-mers screened.

9. **G2 and G3 are demonstrations, not falsifiers.**
   - G2 is guaranteed to show bias.
   - TOP, PRTE and Kozak are host-mRNA elements, so non-recovery is uninformative.
   - Degenerate regexes have their own multiplicity.
   
   *Fix:* Add a planted-motif spike into real viral backgrounds at realistic frequency as the positive control. Keep G3 descriptive.

10. **The "Candidate" label.** It is appropriately hedged. Still, state that enrichment may reflect phylogeny, coding, or structure constraints, not function. Report the Markov-2 cross-check for all reported hits, not only the top hits.
